## Описание

Специализированная ERP-система, разработанная для оптимизации рабочих процессов внутри бюджетного учреждения (ССМП). Проект спроектирован для работы в **изолированной локальной сети**, обеспечивая высокую скорость доступа и безопасность внутренних данных.

Система автоматизирует учет запчастей, управление справочниками и мониторинг состояния ресурсов учреждения.

---

## Инструменты

### Backend

- **Node.js & Express** — основной серверный движок.
- **Sequelize ORM** — мощная работа с базой данных и миграциями.
- **SQLite** — надежное хранение данных в виде файлов (удобно для миграций и бэкапов).
- **Multer** — обработка загрузки медиафайлов (фото/видео).

### Frontend

- **React** — современный интерфейс с компонентным подходом.
- **Mantine UI** — профессиональная библиотека компонентов и удобный Layout.
- **TanStack Query** — продвинутое управление серверным состоянием и кэшированием.
- **Tabler Icons** — минималистичные иконки.

---

## Развертывание (Production)

Система развернута на сервере под управлением **Ubuntu 26.04 LTS**.

### Стек деплоя:

- **Nginx** — реверс-прокси, раздача статики (фронтенда) и обработка `/uploads`.
- **PM2** — менеджер процессов для бесперебойной работы бэкенда.

### Команды управления:

```bash
# Перезапуск бэкенда
pm2 restart jupiter-backend

# Перезапуск Nginx
sudo systemctl restart nginx
```
